# high 全程与三类通用质量要求

在codex/v1-tool-hardening上协调一次通用要求，不修改原版自动预览、编辑器、状态机制或默认关闭的独立复核。

- 精度：所填事实保留时间粒度、数值、单位及限定条件；只有用户授权或模板明确要求其他粒度时才转换，日期占位或版式习惯不是删信息的依据。
- 角色/状态：区分源与目标身份、计划/分配与实际执行/确认；无明确连接且未授权推断则留空，不先猜填再用歧义声明背书。
- 完整性：按可见标签、说明与用户要求理解一栏的多个属性，填写有依据部分并具体报告缺项，不以条目数量/长段文字代替覆盖。

上述要求直接替换或补充原有条目，并在已有成品检查中统一核对，不新增固定流程、业务映射或样本分支。

配置默认从max变high，覆盖RuntimeConfig、LLM客户端默认/请求构造、CLI帮助、.env.example和README。显式CLI/API/环境设置仍优先；不改用户密钥文件。检查阶段使用同一配置，不自动升级max，不新增模型调用。
