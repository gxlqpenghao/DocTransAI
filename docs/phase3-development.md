# 第三阶段 XLSX 模板编辑与输出

第三阶段的通用 XLSX 工程能力与定向验收已完成。单条、已填模板清理与多条记录均有已检查结果，但多条主流程两次未完成，最后经单独版式复核完成，不能表述为三个场景均首次自主通过。

## 架构与通用性

继续在 `codex/document-tools-refactor` 的独立 worktree 开发。只增加 `documents/xlsx.py` 后端；`convert` 根据目标扩展名选择 DOCX/XLSX，模型循环、DataProxy 读取、源图/源页查看、预览覆盖检查和 finish 流程共用。模型仍为 kimi-k3。

模型只收到当前输出格式对应的编辑 schema。没有增加业务槽位、样本映射、固定答案或针对文件名/字段的分支。已有模板及人工核对值只用于验收。

## 工具能力

- `inspect_document`：工作表、单元格值/公式、合并区、图片起始锚点、冻结位置、打印区域与重复标题。初始视图限 20 行/40 列，超过范围明确标记，可按 `s0!A21:Y40` 继续读取。详细格式读取不改变默认列宽。
- `set_cells`：精确形状矩阵；数字、布尔值与显式日期保持类型；空值用于清理。以 `=` 开头的字符串保持文字，不隐式转成公式。超长文本明确拒绝，不静默截断。
- `set_formula`：明确公式写入和旧公式预期值。普通写入不可覆盖公式；其他公式保持不变。
- `copy_rows`：复制完整行/列块到明确的空白目的行，不插入/移动其他记录。复制样式、行高、完整合并区，并平移相对公式引用，保持绝对引用。含部分合并、非空目的区或需要联动的复杂表结构会拒绝。
- `set_cell_images`：图片归属由模型传入资产引用；按单元格尺寸等比放入，一个单元格可有多图。空列表仅删除该锚点的旧图。先调整尺寸后放图。
- `format_cells`、`set_print_area`：显式行高、列宽、对齐、换行与数字格式，以及实际打印范围、方向和重复行/列。宽表可以横向分页，不强行缩到不可读的一页。
- 原子批次、版本校验、幂等与失败回滚；保存后重新载入图片流，避免后续保存丢图。保留 customXml 原始字节及其关系/内容类型，检查包内关系目标存在。

行复制有明确边界：暂不自动扩展 Excel Table、条件格式、数据验证、链接/批注或复制已有图片。这些对象在普通内容写入时保留，行复制遇到需要联动时报告不支持。宏、透视表、外部链接、复杂绘图形状及不可靠的扩展对象提前拒绝。

## 验证

定向测试覆盖类型、重复保存图片、局部图片清理、公式保护、跨表/绝对引用保留、完整合并复制、回滚、隐藏工作表、数据验证与打印设置、自定义 XML、只读检查不改变列宽，以及真实转换入口的格式选择与最终扩展名。没有运行全量历史矩阵。

另外通过独立 Artifact Tool 计算引擎验证复制后的公式：两条记录计算值为 6、12，跨表汇总为 18，公式错误扫描为零，两张工作表均已视觉检查。导入未缓存的公式后，在验证引擎内重新标记公式计算；没有把其结果偷偷写回产品输出。产品后端保护/平移公式并设置打开时重算，不提供完整 Excel 计算引擎，也不保证 data_only 读取立即取得新缓存值。

多条记录重跑在修正部分行高后，最后一次模型检查达到 900 秒上限，仍保留草稿，没有发布成品。后续另起仅修正版式的任务，核对所有值/公式/图片不变，并将结果单独记录；不把它算作原转换自主成功。

多条记录的初次失败促成通用反馈改进：预览直接返回已看页和缺页，finish 错误明确列出缺页编号。修复后按原预算重新运行，单独记录结果，不覆盖原失败。

## 剩余问题与限制

已填模板运行把时间写成字符串，虽然显示内容正确，仍不满足最理想的类型化输出。没有按列名自动猜测并改写日期，也没有改动模型答案掩盖问题。此问题与第二阶段的日期/角色语义问题一起进入第四阶段独立复核。

宽表沿用模板横向分 3 页；合并标题跨页时位于中间页，末页有原合并边线，属于保留模板结构的结果。没有为了样本美观强制拆表或重建标题。必要时模型可显式指定重复标识列，提升多页记录对应的可读性。

真实台账没有公式；公式能力由独立结构/计算变体验证，不能据此声称已验证所有 Excel 函数、外部链接或复杂报表。历史 29 个 case 未全量重跑。
