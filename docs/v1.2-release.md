# DocTransAI 1.2 配置与开发接入版

本版解除转换与审计流程的K3模型锁定，沿用1.1的DataProxy双通道接入与字段审计。正式使用说明集中于[README](../README.md)。

## 配置变化

- remote、convert、review、audit统一支持model、max-output-tokens、reasoning-effort、temperature、llm-timeout-seconds和token-parameter。
- 可选择兼容Chat Completions、图片输入、函数工具调用及SSE响应的服务商模型ID。其他原生协议需适配器或网关。
- 参数按显式CLI/Python、环境变量、指定配置文件、默认值的顺序解析；显式预算可以覆盖无效的低优先级环境设置。
- K3默认保持high与温度1.0；其他模型默认省略思考强度和温度。显式配置可发送服务商支持的强度，omit明确省略字段，不等于服务端关闭思考。
- 可选择max_tokens或max_completion_tokens，可关闭stream_options.include_usage以兼容不支持它的网关。
- 指定的env文件现在同时用于DataProxy授权、LLM和渲染设置，不需要开发人员另行source文件；不自动读取当前目录.env、不执行shell内容。
- README补齐部署依赖、项目Key填写、Python/CLI接入、交付物结构、审计类别、参数表、失败恢复与能力边界。

## 验证

定向回归 **136 passed**：

```bash
uv run pytest tests/test_audit.py tests/upstream/test_service.py \
  tests/upstream/test_remote_workflow.py tests/data_layer \
  tests/integration/test_document_tools.py \
  tests/integration/test_independent_review.py tests/llm -q
```

新增测试覆盖模型不被锁回K3、文件/环境/显式参数优先级、非K3思考强度发送、省略温度与思考字段、两种token请求字段、流式usage兼容开关，以及从同一后端配置文件读取项目授权。`uv sync --locked`通过，版本命令返回1.2.0。

这些新模型测试使用MockTransport核验请求契约，没有声明已在各服务商上跑过真实转换。已有5080→集团DataProxy的真实K3转换和审计证据保留在[1.1验收记录](v1.1-release.md)。本次不重跑模型、不改变集团服务或5080上已验证的1.1运行镜像。

版本1.1.0保持不变；1.2.0新增配置能力并更新源码交付。模板保真、工具边界、来源约束和人工签发责任延续原有设计。
