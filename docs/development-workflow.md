# 正式运行与开发分支

正式运行代码固定在 `main`。每个仓库只保留一条开发分支 `codex/development`；发布经过检查后快进或合并到 main，开发目录不得作为常驻服务的代码目录。

团队仓库与个人公开仓库使用独立历史，不能直接合并团队历史到公开仓库。同步时只同步审核过的代码和文档；业务样本、内部验收材料、密钥、输出、备份和 Git stash 不上传公开仓库。

建议为 main 与开发分支分别保留工作目录。常驻服务的 Python、PYTHONPATH、工作目录应全部指向 main 的同一个目录。开发实验仅在开发目录运行，并使用独立输出目录和端口。切换运行版本前检查活动任务，避免重启中断转换。

发布检查：相关测试通过、真实密钥扫描无匹配、无未提交代码、明确记录尚未验证的远端接口与模型能力。分支发布不等于外部服务故障已解决，也不自动变更版本号或发布标签。
