# 扩展样本候选：从文件类型汇总筛选

本目录是从 `文件类型汇总` 再筛出的一批候选样本，用来扩展 V1 验证覆盖面。这里先不直接并入正式批跑清单，待人工确认后再生成 DataProxy fresh bundle，并晋升到 `05_样本配对_Manifest`。

## 筛选原则

- 不按固定模板族筛选，而按转换压力点筛选：同源多模板、字段不完全匹配、长文档摘要整理、表格行记录、扫描/图片 PDF、图片抽取与按模板回填。
- 一份原始文档可以对应多个模板，用来验证 agent 是否能按不同输出对象重组内容。
- 模板字段允许与源文档不完全一致，用来验证缺失字段是否留空、不乱填。
- 图片样本优先选有多张图片、图片附近有说明文字、或图片在表格/附件区内的文档。

## 晋升口径

1. 人工确认本目录样本和配对是否合理。
2. 对确认的源文档生成 DataProxy fresh bundle，产物仍落在 DocTransAI 自己的 `artifacts/` 目录。
3. 将确认配对转写入正式 V1 manifest，状态先用 `observe`，真实跑通且人工验收后再改为 `ready`。T04/T05 这类已填样例模板需要设置 `normalize_sample_template: true`。
4. 图片样本优先审核：是否抽到图片资产、图片是否与附近文字/表格行关联、模板中是否按可接受的近似位置回填。
