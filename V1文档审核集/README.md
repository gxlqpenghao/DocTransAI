# V1 文档审核集

本目录用于先行审核 V1 验证开发所需样本。原始资料未移动、未修改；这里的文件均为复制件。

## 目录角色

- `01_被转换文档_Source`：作为输入文档，用于验证信息抽取能力。
- `02_目标模板_Template`：作为目标模板，用于验证模板理解、字段填充和版式输出。
- `03_参考成品_Reference`：已填好的真实成品，不作为模板优先使用，主要用于人工比对生成结果是否合理。
- `04_V1暂缓样本_Deferred`：暂不建议放入 V1 主验收，后续作为 V1.5 或压力测试样本。
- `05_样本配对_Manifest`：V1 批量验证用例清单，显式描述 bundle、record、template、reference 的配对关系。
- `06_扩展样本候选_文件类型汇总`：从 `文件类型汇总` 二次筛选出的候选样本包，先供人工审核，不直接进入正式批跑。

## 建议审核方式

1. 先确认 `Source` 是否能代表 V1 需要支持的输入类型。
2. 再确认 `Template` 是否能代表 V1 需要验证的输出类型。
3. `Reference` 只用于比对，不建议第一轮直接当空模板。
4. `Deferred` 若业务方强烈要求提前纳入，应单独标记为 OCR/复杂文档专项验收，不要混入 V1 基础验收。
5. `Manifest` 用于驱动批量验证；目录内的素材文件不自动推断配对关系，以 manifest 为准。
